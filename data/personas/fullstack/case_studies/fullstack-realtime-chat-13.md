# Real-time chat module for a nonprofit seed-stage startup

**Client:** a seed-stage startup in nonprofit · **Duration:** 6 weeks · **Year:** 2023

## The problem
The client's team had a recurring pain: users left the app to talk to each other. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered in-app real-time messaging with read receipts and moderation. I worked with Node.js, WebSockets, React and Redis, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system increased daily active users by 31%. The client extended the engagement for a second phase.
