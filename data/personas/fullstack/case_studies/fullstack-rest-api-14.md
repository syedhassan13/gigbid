# Public REST API and developer portal for a real estate regional chain

**Client:** a regional chain in real estate · **Duration:** 4 weeks · **Year:** 2025

## The problem
The client's team had a recurring pain: partners integrated through ad-hoc CSV drops. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered a versioned public API with keys, rate limits and docs. I worked with REST API, Node.js, OpenAPI and PostgreSQL, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system onboarded 60 partners in the first quarter. The client extended the engagement for a second phase.
