# Internal admin panel for a e-commerce consultancy

**Client:** a consultancy in e-commerce · **Duration:** 12 weeks · **Year:** 2026

## The problem
The client's team had a recurring pain: ops staff edited records directly in the database. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered an audited admin panel with roles and approvals. I worked with React, Django, role-based access and Python, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system eliminated 60 direct DB edits per week. The client extended the engagement for a second phase.
