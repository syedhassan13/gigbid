# A/B test analysis program for a hospitality consultancy

**Client:** a consultancy in hospitality · **Duration:** 6 weeks · **Year:** 2025

## The problem
The client's team had a recurring pain: experiments were called early on noisy results. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered a pre-registered testing process with power analysis and readouts. I worked with A/B testing, statistics, Python and SQL, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system cut false-positive launches by 40%. The client extended the engagement for a second phase.
