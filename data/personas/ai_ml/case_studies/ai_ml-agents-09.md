# Multi-step LLM agent for operations for a fintech mid-size agency

**Client:** a mid-size agency in fintech · **Duration:** 10 weeks · **Year:** 2025

## The problem
The client's team had a recurring pain: a repetitive back-office workflow took a full-time person. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered a tool-using agent with human approval for every external action. I worked with LLM, AI agents, Python and API integration, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system handled 18% of tickets end-to-end with approval. The client extended the engagement for a second phase.
