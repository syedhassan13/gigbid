# Product recommendation engine for a media regional chain

**Client:** a regional chain in media · **Duration:** 3 weeks · **Year:** 2021

## The problem
The client's team had a recurring pain: customers rarely discovered relevant products. They needed something reliable that their non-technical staff could trust.

## What I built
I designed and delivered personalised recommendations served from an API with nightly retraining. I worked with recommender systems, Python, machine learning and SQL, and set it up so the client's team could run it without me. Long-running work runs in the background so users never wait.

## Outcome
Within the first months the system lifted click-through by 31%. The client extended the engagement for a second phase.
