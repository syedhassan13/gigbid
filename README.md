# GigBid: a multi-agent freelancer copilot

GigBid finds freelance jobs, decides whether they are worth bidding on, writes proposals in which **every claim
links to real portfolio evidence**, and manages client conversations. **Nothing reaches a client until you
approve it.**

LangGraph multi-agent system · advanced RAG with measured variant choice · three MCP servers (+ official
Upwork and GitHub MCP) · FastAPI + React · durable Postgres checkpoints · open-weight models first.

## What it does
1. **Scout** runs your saved searches on a schedule, de-duplicates them and queues new jobs.
2. **Job Analyst**, **Risk Assessor** and **Fit Matcher** run *in parallel*. They produce a JobSpec, a risk
   report (scams, free-work asks, off-platform requests, planted prompt injections) and a requirement→evidence matrix.
3. A decision node picks bid, watch or skip, with reasons. **Pricing Strategist** prices from real market
   percentiles (1.25M Kaggle Upwork rows) and checks the Connects cost is worth it.
4. **Proposal Writer** drafts. A **claim verifier** removes unsupported claims, the **Critic** sends the draft
   back at most twice, and the **Compliance Guard** enforces the policy pack.
5. **You approve, edit or reject** in the Proposal Studio. Hover any claim to see its evidence and check the
   dry-run cost. Only then is it submitted, exactly once even across crashes.
6. **Client Liaison** drafts replies and interview slots behind the same approval gate. Outcomes and your edits
   update memory only through explicit promotion rules.

## Run it
```bash
cp .env.example .env            # add GROQ_API_KEY (open profile); leave empty to run fully offline
pip install -e ".[dev]" && (cd apps/web && npm ci && npm run build)
make seed                        # personas + GigSim data (+ Kaggle stats if data/raw present)
python scripts/dev.py --demo     # GigSim :8100, API :8000 (serves the web build), web dev :5173
# or everything in containers:
docker compose -f infra/docker-compose.yml up --build
```
`make test` runs the tests, `make eval` runs the full evaluation, and `make eval-smoke` runs the CI smoke eval with thresholds.

## Data and honesty
Personas, GigSim and the dev set are **synthetic** and labelled as such. Job titles, budgets and client
statistics come from **real Kaggle datasets** (ODC-By / Apache-2.0); see [docs/DATA_CARD.md](docs/DATA_CARD.md).
AI assistance is disclosed in [docs/AI_USAGE.md](docs/AI_USAGE.md).
